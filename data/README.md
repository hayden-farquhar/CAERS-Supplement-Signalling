# Data

Raw CAERS data files are not included in this repository due to file size. To reproduce the analysis, download the data from the FDA website.

## Downloading CAERS/HFCS Data

1. Visit the FDA CAERS/HFCS download page: https://www.fda.gov/food/compliance-enforcement-food/cfsan-adverse-event-reporting-system-caers
2. Download both CSV files:
   - **CAERS_case_based.csv** — Case-based adverse event reports
   - **CAERS_product_based.csv** — Product-based adverse event reports
3. Place both files in `data/raw/`

The analysis in the accompanying manuscript used data downloaded on 30 September 2025, covering reports received through that date. Results may differ slightly with more recent data releases.

## Processed Data

Running scripts 01 and 02 will generate all processed data files in `data/processed/`. These intermediate files are not included in the repository but are regenerated by the pipeline.
